# MYTHIQON — Creator Portfolio

A cinematic, myth-inspired personal portfolio website designed to showcase digital artwork with dramatic visuals, smooth animations, and a bold modern aesthetic.

## ✨ Overview

**MYTHIQON** is a single-page HTML/CSS/JS portfolio built for artists and creators who want a powerful, mysterious, and premium visual identity.
The design blends mythology, cyberpunk motion, and editorial typography to create a striking showcase.

---

## 🎨 Features

* **Mythic Visual Theme**

  * Dark cinematic palette with accent yellow & red highlights
  * Inspired by gods, legends, and powerful archetypes

* **Animated Laser Background**

  * Subtle scanning laser lines using pure CSS animations

* **Hero Section**

  * Large display typography
  * Floating animation for depth
  * Creator stats panel

* **Portfolio Grid**

  * 1080 × 1350 aspect-ratio cards (perfect for Instagram art)
  * Hover reveal bios with smooth transitions
  * Tilt + scale hover interaction

* **Scroll Reveal Animations**

  * Elements animate in as you scroll
  * Lightweight vanilla JavaScript (no libraries)

* **Responsive Design**

  * Adapts cleanly to tablets and mobile screens

## 🎛️ Customization Guide

### 🎨 Change Theme Colors

Edit the CSS variables inside `:root`:

```css
:root {
  --accent-yellow: #F5DF4D;
  --marvel-red: #E62429;
  --deep-black: #050505;
  --off-white: #F2F2F2;
}
```

---

### 🖼️ Replace Portfolio Images

* Replace `ps-4.jpg`, `ps-5.jpg`, etc. with your own images
* Keep a **1080 × 1350** ratio for best results
* Update titles and descriptions in the HTML

---

### ✏️ Edit Portfolio Text

```html
<h2 class="box-title">MEDUSA</h2>
<p class="bio-text">An ancient goddess whose beauty hides a cruel power.</p>
```

---

### 🔗 Social Links

Update contact links in the **CONTACT** section:

```html
<a href="https://www.instagram.com/yourusername">INSTAGRAM</a>
<a href="mailto:youremail@gmail.com">EMAIL</a>
```
